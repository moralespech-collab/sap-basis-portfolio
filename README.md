This repository contains field notes, step-by-step guides (runbooks), and configuration files used in daily SAP system administration. The goal is to document solutions to real-world technical challenges and serve as a quick reference for the SAP Basis community.

## 🛠️ Core Topics
*   **SAP S/4HANA:** Conversions, upgrades, HANA database administration, and performance tuning.
*   **SAP BTP (Business Technology Platform):** Cloud Connector setups, extensions, and integration management.
*   **SAP NetWeaver:** Traditional AS ABAP/Java administration, patching, and Change and Transport System (CTS).

## 📈 Recent & Ongoing Activities
*   [x] **SAP Router:** Installation, SNC certificate renewals, and `SAPROUTTAB` table configuration.
*   [ ] **SAP Solution Manager (SolMan):** Managed Systems Configuration and enabling automated EarlyWatch Alert (EWA) reporting for clients.

## 📁 Repository Structure
*   `/s4hana`: Platform-specific guides for S/4HANA.
*   `/btp`: Cloud environment setups and notes.
*   `/netweaver`: General Basis administration (SolMan, SAP Router, etc.).
*   `/scripts`: Useful scripts (Bash, Ansible, PowerShell) for task automation.
